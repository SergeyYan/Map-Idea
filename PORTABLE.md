# Перенос InkMap

`InkMap-portable.zip` содержит программу и снимок сохранённой доски `data/map.json`, включая загруженные вложения и записи голоса. `InkMap-share.zip` содержит программу без вашей доски и локального файла карты проекта. Для передачи другим людям используйте share-архив.

## Запуск на Windows

Установите Python 3.10 или новее, распакуйте ZIP и откройте PowerShell в папке InkMap:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Для установки зависимостей нужен интернет. Терминал сервера оставьте открытым. На Linux/macOS используйте `.venv/bin/python` вместо Windows-пути.

Браузерные настройки, несохранённая резервная копия и история Undo/Redo не переносятся. Ссылки на файлы вне карты остаются ссылками: сами внешние файлы переносите отдельно и обновляйте их пути. Перед созданием копии дождитесь надписи «Сохранено».

## Подключение собственного Codex

Доска работает без Codex. Для поиска чатов и отправки идей установите Codex CLI, убедитесь, что команда `codex` доступна в терминале, и выполните `codex login` под своим аккаунтом. Перезапустите сервер InkMap после установки CLI, чтобы он получил обновлённый PATH.

Для чтения доски из чата Codex дополнительно настройте MCP. В PowerShell из папки InkMap:

```powershell
codex mcp add inkmap --env INKMAP_URL=http://127.0.0.1:8000 -- "$PWD\.venv\Scripts\python.exe" "$PWD\inkmap_mcp.py"
codex mcp list
```

Если сервер `inkmap` уже зарегистрирован, обновите его существующие пути в настройках Codex вместо создания второй записи. После настройки откройте новый чат или перезапустите клиент Codex. Сервер InkMap должен работать. Попросите Codex прочитать доску через `read_board`.

## Учётные данные

InkMap запускает локальный Codex CLI, используя его текущую авторизацию. Учётные данные Codex в архивы не входят. MCP InkMap связывает Codex с локальной доской и не предоставляет доступ к аккаунту автора программы.

Не переносите `.codex/auth.json`, профиль Codex или системное хранилище паролей вместе с программой. На одной машине под одним пользователем InkMap использует тот аккаунт, в который уже выполнен вход в CLI. Сервер предназначен для localhost и не имеет собственной системы входа.
