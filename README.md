# InkMap — настольная карта идей

**Заметки, связи, скриншоты, видео, голосовые записи и задачи на свободном холсте.** InkMap работает на Windows 10/11 x64 как самостоятельная переносимая программа: без браузера, Python, локального сервера и отдельной установки .NET. Доска доступна без интернета, данные хранятся на вашем компьютере.

1. Скачайте **InkMap-2.1-Windows-x64.zip** по ссылке выше.
2. Полностью распакуйте архив в папку с доступом на запись, например в «Документы».
3. Запустите **InkMap.exe**. Установка и права администратора для работы не нужны.

Кнопка GitHub **Code → Download ZIP** скачивает исходники репозитория. Для запуска готовой программы используйте **Windows ZIP из релиза**.

## Возможности

- **Идеи и заметки:** свободное размещение карточек, пять видов фигур, цвета, теги и полная заметка в панели деталей.
- **Связи:** протягивание из любой точки родителя к другой карточке, автоматические выходы, плавные линии, направления и приоритеты. Поддерживаются 20 и более отдельных выходов.
- **Медиа:** встроенные изображения, скриншоты, аудио, видео и запись голоса. Ctrl+V вставляет текст, изображение или медиафайлы из буфера Windows.
- **Задачи и Roadmap:** статусы, этапы и переход от плана к нужной карточке.
- **Редактор:** выделение рамкой, групповое перемещение, изменение размеров, масштаб 5–200%, рисунки и ластик, Undo/Redo, светлая и тёмная темы.
- **Данные:** фоновое автосохранение, резервная копия `.bak`, импорт/экспорт JSON и импорт Markdown.
- **Проекты:** чтение `.inkmap/project.json`, замена или синхронизация с сохранением ручных заметок, вложений и размещения.

## Управление

| Действие | Управление |
| --- | --- |
| Создать идею | Двойной клик ЛКМ на пустом холсте или кнопка «+» |
| Перемещать холст | Зажать ПКМ и двигать мышь |
| Контекстное меню | Короткий клик ПКМ |
| Выделить группу | Протянуть рамку ЛКМ на пустом фоне; Ctrl+клик добавляет или исключает карточку |
| Переместить карточку или группу | Перетащить выбранную карточку ЛКМ |
| Изменить размер | Потянуть нижний правый угол выбранной карточки |
| Открыть полную заметку | Двойной клик по карточке |
| Создать связь | ПКМ по карточке → «Связать» или кнопка ↗; тянуть из родителя на другую карточку |
| Настроить связь | Клик по видимой линии |
| Масштаб | Колесо мыши или кнопки «+» / «−» |
| Показать всю карту | Home |
| Отменить / вернуть | Ctrl+Z / Ctrl+Shift+Z или Ctrl+Y |
| Удалить выбранное | Delete вне текстового поля |
| Вставить из буфера | Ctrl+V |
| Сохранить немедленно | Ctrl+S; обычно работает автосохранение |
| Завершить инструмент | Escape |

## Сохранение, перенос и обновление

В переносимой сборке карта со встроенными вложениями находится в **data/map.json** рядом с EXE. Предыдущая сохранённая версия — **data/map.json.bak**. Файл `portable.flag` включает хранение рядом с программой; без него используется `%LOCALAPPDATA%\InkMap`.

**Перенос на другой компьютер:** дождитесь статуса «Сохранено на компьютере», закройте приложение и скопируйте всю папку, включая `data` и `portable.flag`.

**Обновление с настольной версии 2.0/2.1:** закройте программу и замените **только InkMap.exe** новым файлом. **Не удаляйте и не заменяйте свою папку data.**

**Переход с прежней веб-версии:** выберите «Импорт» и откройте старый `data/map.json` либо JSON-экспорт. Импорт заменяет текущую доску и отменяется через Undo; исходный файл сам по себе не изменяется. Markdown импортируется по иерархии заголовков.

Одна карта открывается одним экземпляром программы. Не редактируйте её файл извне во время работы и не используйте одну рабочую папку одновременно на двух компьютерах через сетевой диск или облачную синхронизацию. История Undo/Redo сохраняется в памяти до закрытия программы. Внешние файлы, указанные только путями, переносите отдельно.

## Вложения и голос

Изображения, аудио и видео **до 5 МБ на файл** хранятся внутри карты; общий предел встроенных медиа — **150 МБ на карту**. Вложения открываются в окне программы. Для аудио и видео используются кодеки Windows; MP4/H.264, MP3 и WAV наиболее совместимы. Некоторые форматы, включая WebM и OGG, могут требовать дополнительных системных кодеков.

Голос записывается с микрофона Windows по умолчанию в WAV, моно 16 кГц, до 150 секунд. Выбор микрофона и разрешение доступа для классических приложений задаются в параметрах Windows.

## Контекст для Codex

Кнопка **«Контекст Codex»** экспортирует `IDEAS.md` с заметками, статусами, связями и ссылками вложений. Добавьте этот файл в чат Codex вручную. Бинарные медиа в Markdown не передаются. Автоматическая отправка в чаты и серверный MCP прежней версии в настольную сборку не включены. Для самой доски Codex не нужен.

## Версии и исходники

**Актуальная программа — настольный InkMap 2.1 в [Releases](https://github.com/SergeyYan/Map-Idea/releases/latest).** Нативные C#/WPF-исходники и инструкция сборки приложены к релизу отдельным архивом [InkMap-2.1-source.zip](https://github.com/SergeyYan/Map-Idea/releases/download/v2.1.0/InkMap-2.1-source.zip). Для разработки требуется .NET SDK 10; готовый EXE уже содержит среду выполнения.

Основная ветка пока хранит исходники прежней веб-версии на FastAPI/JavaScript. Её запуск и прежняя интеграция Codex описаны в [инструкции веб-версии](docs/WEB-VERSION.md). Эти инструкции не нужны для запуска настольного EXE.

Сборка предназначена для Windows x64; ARM, 32-битная Windows, Linux и macOS не проверены. EXE не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen. Проверка на разных устройствах, DPI, микрофонах и кодеках остаётся необходимой; технические результаты и ограничения приведены в описании релиза и документации внутри архива.
