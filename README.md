# InkMap — карта идей

Локальная доска для идей и проектов: заметки, связи, фотографии, скриншоты, видео, аудио, голосовые записи, рисунки и задачи на свободном холсте. Работает в браузере; карта сохраняется на вашем компьютере.

## Запуск на Windows

Требуются **Python 3.10+** с доступной командой `python` и интернет для установки зависимостей при запуске.

1. Скачайте проект через **Code → Download ZIP** или клонируйте репозиторий и распакуйте его в отдельную папку.
2. Откройте **`server_control_launcher.bat`** двойным кликом.
3. В окне управления нажмите **«Запустить»**, дождитесь статуса сервера и нажмите **«Открыть в браузере»**.
4. Доска доступна по адресу **http://127.0.0.1:8000**.

В окне управления есть кнопки **«Запустить»**, **«Остановить»**, **«Открыть в браузере»** и **«Обновить»**. Кнопка «Обновить» проверяет состояние сервера.

Можно запускать сервер напрямую через **`start_server.bat`**, а останавливать через **`stop_server.bat`**. Батник запуска создаёт `.venv`, устанавливает зависимости и запускает сервер в фоне. Закрытие браузера не останавливает сервер. Для работы самой доски Codex не требуется.

После обновления исходников перезапустите сервер и обновите страницу через **Ctrl+Shift+R** или **Ctrl+F5**, чтобы открытая вкладка загрузила новый код.

## Управление

| Действие | Управление |
| --- | --- |
| Перемещаться по карте | Зажать **ПКМ** и двигать мышь |
| Открыть контекстное меню | Короткий клик **ПКМ** на фоне, карточке, связи или рисунке |
| Создать идею | Двойной клик **ЛКМ** на пустом фоне или кнопка добавления |
| Выбрать карточку | Клик **ЛКМ** по карточке |
| Выделить несколько объектов | Зажать **ЛКМ** на пустом фоне и протянуть рамку |
| Переместить карточку или выделенную группу | Зажать **ЛКМ** на карточке и перетащить; за заголовок удобно двигать карточки с длинными заметками |
| Приблизить / отдалить | Колесо мыши над холстом или кнопки «+» / «−», диапазон **5–200%** |
| Изменить размер | Потянуть маркеры по краям и углам выбранной карточки |
| Редактировать заметку внутри карточки | Двойной клик по карточке |
| Сохранить встроенную правку | **Ctrl+Enter** или выход из редактора |
| Отменить встроенную правку | **Escape** |
| Вставить содержимое буфера | **Ctrl+V** на доске |
| Отменить / вернуть действие | **Ctrl+Z** / **Ctrl+Shift+Z** |
| Удалить выбранную карточку или связь | **Delete** вне текстовых полей |
| Завершить инструмент / закрыть меню | **Escape** |

ЛКМ — левая кнопка мыши, ПКМ — правая. На сенсорном экране перетаскивание фона перемещает холст. Перемещение группы отменяется одним Undo. Длинные заметки показывают полный текст и прокручиваются внутри карточки; колесо над прокручиваемой заметкой не меняет масштаб карты.

## Фото, скриншоты, аудио и видео

**Вставка через Ctrl+V:** скопируйте изображение или скриншот, наведите курсор на холст и вставьте. Создаётся новая карточка; текст из буфера создаёт заметку. Видео и аудиофайлы также вставляются, если браузер предоставляет их через буфер обмена. В полях ввода работает обычная вставка текста.

**Добавление файла:** выберите идею или фигуру и в правой панели используйте поле «Изображение, видео или аудио». Поддерживаются вложения **до 5 МБ каждое**. Для показа вложений выберите раскрытие **«Все детали и медиа»**. Изображение масштабируется при изменении ширины карточки; аудио и видео получают элементы воспроизведения, если формат поддерживается браузером.

Если файл из Проводника не вставляется через Ctrl+V, добавьте его через выбор файла в панели. Встроенной съёмки фото или записи видео с камеры нет: готовые фото и видео можно добавить как вложения.

**Видео по ссылке:** в панели можно добавить HTTP(S)-ссылку на видео или путь к локальному файлу. Ссылка на сайт открывается отдельно. Путь к локальному видео сохраняется как ссылка для контекста проекта — браузер не воспроизводит файл по такому пути. Для воспроизведения загрузите сам видеофайл. Для передачи пути Codex заполните «URL или путь для Codex».

### Запись голоса прямо на доске

1. Выберите карточку или фигуру.
2. Нажмите **«Записать с микрофона»** и разрешите доступ к микрофону.
3. В нижней панели нажмите **«Остановить и добавить»** или **«Отменить запись»**.

Запись прикрепляется к исходной карточке, даже если вы выбрали другой объект. Её можно прослушать, удалить и вернуть через Undo. Автоостановка — через 10 минут или примерно 3 МБ; окончательный предел вложения — 5 МБ. Формат зависит от браузера. Требуется localhost или HTTPS; автоматического распознавания речи в текст пока нет.

## Заметки, фигуры, рисунки и связи

В правой панели редактируются заголовок, заметка, теги, статус, этап, заливка и уровень раскрытия. Панель можно скрыть кнопкой на её левом краю. Есть светлая и тёмная темы.

Фигуры: овал, прямоугольник, скруглённый прямоугольник, ромб и треугольник. Размер меняется маркерами; кнопка «Вернуть автоматический размер» сбрасывает ручной размер.

Инструмент рисования позволяет делать штрихи на холсте. Ластик удаляет весь затронутый штрих; несколько штрихов можно стереть одним движением.

Для связи нажмите **«Связать»**, затем основную идею и подидею. Клик по линии открывает её настройки: конечные узлы, направление и приоритет. Доступны обычный, важный и высокий приоритеты, односторонние и взаимные стрелки или линия без стрелок. Связи следуют за карточками при перемещении и изменении размеров. Повторная связь той же пары открывает существующую линию.

## Задачи и Roadmap

Назначьте карточкам статусы «К выполнению», «В работе» или «Готово» и укажите этапы. Во вкладке **Roadmap** задачи группируются по этапам и показывается прогресс выполнения.

## Сохранение, экспорт и перенос

Изменения сохраняются автоматически в **`data/map.json`**. Дождитесь надписи «Сохранено» перед переносом. Изображения, загруженные видео, аудио и голосовые записи хранятся внутри карты.

- **JSON-экспорт** сохраняет всю карту, включая вложения и рисунки. JSON можно импортировать обратно.
- **Markdown-импорт** создаёт идеи и связи по иерархии заголовков.
- **«Контекст для Codex»** выгружает `IDEAS.md` с заметками, статусами, связями и ссылками вложений.
- **«Новая карта»** очищает доску; действие можно отменить через Undo.

Для переноса на другую станцию используйте portable-архив с `data/map.json` либо скопируйте этот файл вместе с программой. GitHub-исходники не включают вашу рабочую доску. Внешние файлы, на которые указаны пути, переносите отдельно. История Undo/Redo и настройки браузера не переносятся. Подробнее: [PORTABLE.md](PORTABLE.md).

Запускайте один сервер и один worker. При конфликте нескольких вкладок экспортируйте локальную карту перед перезагрузкой. Сервер предназначен для localhost: собственной аутентификации у него нет.

## Работа с Codex

«Загрузить из проекта» читает `.inkmap/project.json` и отображает структуру проекта на доске. Можно заменить карту или синхронизировать узлы с сохранением ручных заметок и размещения.

MCP InkMap позволяет открытому чату прочитать сохранённую доску через `read_board` и предложить дополнения через `propose_map`. Предложения применяются пользователем на доске.

Кнопка отправки идеи использует отдельный процесс Codex CLI. Отправка в чат, открытый другим процессом Codex, ограничена; совместимость нового протокола разрешений с Windows ещё дорабатывается. Пока можно попросить открытый чат прочитать конкретную идею через MCP. Подробнее: [CODEX-INTEGRATION.md](CODEX-INTEGRATION.md).

## Для разработчиков

Ручной запуск без батников:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Основные проверки:

```powershell
node tests/editor.mjs
node tests/proposals.mjs
node tests/project-sync.mjs
.\.venv\Scripts\python.exe tests/codex_discovery.py
.\.venv\Scripts\python.exe tests/codex_backend.py
```

Браузерные проверки требуют Playwright и Edge. `tests/selection.cjs`, `tests/paste.cjs` и `tests/notes-scroll.cjs` используют изолированные тестовые карты. Другие браузерные сценарии и необходимые адреса сервера описаны в соответствующих файлах тестов.

Карта проекта обновляется по staged-снимку перед коммитом и проверяется перед push через Git-хуки. После клонирования подключите их заново: `python project_map.py --install-hooks`. Это статическая карта исходников, а не подтверждение выполнения тестов.
