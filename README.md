# InkMap

Локальное приложение для идей: свободный холст, связи, заметки с тремя уровнями раскрытия, фигуры, рисование, медиа, задачи и Roadmap.

## Запуск

Требуется Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Сервер хранит карту в `data/map.json`. Не выставляйте этот локальный сервер в интернет: аутентификация не предусмотрена.

## Работа

- Двойной клик по фону создаёт идею. Перетаскивание карточки перемещает её, перетаскивание фона перемещает холст.
- «Связать»: нажмите сначала основную идею, затем подидею. Новая связь направлена от первой ко второй; после создания открывается редактор связи. Escape завершает инструмент. Для удаления выберите идею и нажмите «Убрать связь» рядом с нужной связью в панели. Удаление поддерживает Undo/Redo и автосохранение.
- Редактирование панели фиксируется при выходе из поля. Все изменения документа проходят через общую историю, Ctrl+Z / Ctrl+Shift+Z отменяют и возвращают действия.
- Вложения: изображения, локальные видео и аудио до 5 МБ каждое. Полное раскрытие показывает медиа. Видео также можно добавить по HTTP(S)-ссылке или пути к файлу без загрузки в карту; ссылка на сайт открывается в отдельной вкладке. Локальный путь служит ссылкой для Codex, браузер не воспроизводит файл по такому пути. У загруженного видео можно вручную указать источник в поле «URL или путь для Codex»: браузер скрывает полный путь выбранного файла. Распознавание речи пока не реализовано.
- Статусы задач и произвольные этапы собираются в Roadmap.
- Markdown импортируется по иерархии заголовков. JSON экспорт сохраняет весь документ, включая вложения и рисунки.
- «Контекст для Codex» создаёт `IDEAS.md`: положите его в папку вашего проекта и попросите Codex прочитать. Экспорт содержит ссылки на видео с сайтов и указанные пути локальных видео; для старых вложений без источника показывает напоминание указать путь. Доступ к локальным файлам нужно предоставить Codex отдельно. Прямая интеграция с API пока не реализована.

## Инструменты холста

- Delete удаляет выбранную идею, фигуру или связь. При удалении узла удаляются его связи; Undo возвращает узел вместе со связями. В текстовых полях Delete удаляет символы, сохраняя объект.
- Колесо мыши меняет масштаб относительно курсора (30–200%).
- ПКМ на пустом месте: создание идеи или фигуры, рисование, ластик. ПКМ на идее/фигуре: редактирование и удаление; для фигуры — выбор формы. ПКМ на связи: изменение конечных узлов и удаление. ПКМ на рисунке: удаление штриха.
- Цвет идей и фигур: выберите объект → «Цвет заливки» в панели или ПКМ → «Цвет заливки…». Палитра содержит готовые цвета, «Свой цвет» открывает произвольный цвет, «По теме» возвращает стандартную заливку. Текст подбирается контрастным к выбранному цвету. Цвет хранится в карте, поддерживает Undo/Redo и JSON импорт/экспорт, сохраняется при переключении светлой/тёмной темы.
- Форма выбирается перед созданием в панели инструментов или после создания в панели объекта: овал, прямоугольник, скруглённый прямоугольник, ромб, треугольник. Старые фигуры без указанной формы отображаются овалом.
- Ластик удаляет весь затронутый штрих. Протяните по нескольким штрихам, чтобы удалить их одним действием истории. Escape завершает инструмент или закрывает меню.
- Тёмная тема меняет холст, карточки, текст, поля, Roadmap, линии и рисунки. Выбор темы сохраняется в браузере отдельно от документа.

## Приоритет и направление связей

- Выберите линию кликом или ПКМ → «Редактировать связь». В панели идеи также доступна кнопка «Изменить» рядом со связью.
- «Обычный» — тёмная линия на светлой теме, белая на тёмной; «Важный» — оранжевая; «Высокий» — красная. Высокий приоритет также обозначается более толстой линией. Выделение не заменяет цвет приоритета.
- Направления: A → B, B → A, взаимная A ↔ B или связь без стрелок. Односторонняя стрелка означает «основная идея → подидея». Стрелки заканчиваются у границ карточек; положение обновляется при перемещении и изменении размеров заметок.
- Приоритет и направление поддерживают Undo/Redo, автосохранение и JSON импорт/экспорт. В `IDEAS.md` передаются направление, основная идея/подидея и приоритет, чтобы Codex видел структуру.
- При выборе связи на карточках показываются метки «УЗЕЛ A» и «УЗЕЛ B». Повторная попытка связать ту же пару, в том числе в обратном порядке, открывает существующую связь без создания дубля и без изменения истории. Если в старой карте уже есть несколько связей одной пары, они остаются в документе и отображаются отдельными кривыми, включая раздельные наконечники.
- Старые связи без новых полей отображаются с обычным приоритетом и направлением от первого узла ко второму. Направленная связь описывает отношение идей; карта допускает несколько основных идей и циклы.

## Надёжность

Сохранения выполняются последовательно. Сервер проверяет ревизию, предотвращая перезапись из другой вкладки, и записывает документ атомарно с fsync. Несохранённый документ резервируется в localStorage; квота браузера может ограничить большие медиа. При конфликте экспортируйте локальную карту и перезагрузите страницу. История до 100 действий хранится в памяти текущей сессии. Для нескольких процессов сервера блокировка не поддерживается: запускайте один worker.


## Проверки

`node tests/editor.mjs` — проверки геометрии, обработчиков редактора, истории и экспорта без сторонних пакетов.

`node tests/browser.cjs` — сценарий в headless Edge через Playwright (нужны установленный пакет Playwright и доступный Edge; пакет можно подключить через NODE_PATH). Сервер должен быть запущен на порту 8000. Тест подменяет API собственной картой в памяти: сохранённая карта пользователя не изменяется.

`node tests/arrows.cjs` — воспроизведение наложения обратных связей на овале/треугольнике, проверка четырёх направлений, меток A/B, предотвращения дублей и Undo/Redo. Требует ту же браузерную среду; снимки сохраняются в игнорируемую папку `tests/artifacts/`.

`node tests/colors.cjs` — проверка палитры, произвольной заливки, всех форм и идей, контрастного текста, тем, Undo/Redo и восстановления после перезагрузки. Использует отдельную тестовую карту; снимки сохраняются в `tests/artifacts/`.


## Запись голоса

Выберите идею или фигуру → «Записать с микрофона». Браузер запрашивает разрешение. Нижняя панель позволяет остановить и добавить запись либо отменить её, даже после выбора другого объекта. Запись прикрепляется к исходному объекту и открывает полный уровень раскрытия с аудиоплеером. Удаление вложения, Undo/Redo и JSON экспорт работают через существующую модель медиа.

Запрашиваются моно и 24 кбит/с: ориентировочно 180 КБ/мин аудио (в JSON около 240 КБ/мин из-за base64). Фактический формат и размер зависят от браузера: предпочтительно WebM/Opus, затем Ogg/Opus или MP4. Автоостановка через 10 минут или примерно 3 МБ, окончательный предел 5 МБ. Микрофон освобождается после остановки, отмены, ошибки и выхода со страницы. Требуется localhost или HTTPS; распознавание речи не реализовано.

`node tests/voice.cjs` — реальный MediaRecorder в headless Edge с синтетическим микрофоном; проверяет воспроизведение, историю, сохранение, отмену, отказ доступа и освобождение устройства. Запись настоящего микрофона пользователя не выполняется. Требуется Playwright/Edge, как для остальных браузерных проверок.


## Размеры объектов

Выберите идею или фигуру: восемь маркеров по периметру меняют ширину, высоту или оба размера. Масштаб холста учитывается; противоположный край остаётся на месте. Минимум 180 пикселей по ширине, 90 по высоте для идеи и 180 для фигуры; максимум 3000. Содержимое фиксированного размера прокручивается внутри объекта. Связи следуют за изменёнными границами. Размеры сохраняются в карте и JSON-экспорте, одно перетаскивание отменяется одним Undo. В панели есть «Вернуть автоматический размер».

`node tests/resize.cjs` — браузерная проверка размеров идеи и пяти форм, масштаба, связей, истории и восстановления. Требует ту же среду Playwright/Edge и использует отдельную тестовую карту.
