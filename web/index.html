Загрузить доску из проекта

Для существующего чата папка подставится автоматически. Для новой идеи выберите пустую папку или папку с проектом.

При замене удаляются все объекты текущей доски. Undo возвращает предыдущую карту.

Источник доски: .inkmap/project.json в выбранной папке. Чат используется только для выбора папки; запуск Codex для загрузки не нужен.

Кнопка передаст текст заметок, статусы, связи и ссылки вложений в выбранный чат вашей учётной записи Codex. Codex получит доступ на чтение папки проекта. Запрос расходует лимиты Codex. Ответ и новые идеи появятся ниже; код проекта не изменяется.
