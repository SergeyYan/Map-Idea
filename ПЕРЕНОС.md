# Перенос InkMap

В архиве находятся приложение, тесты, инструкция README.md и копия сохранённой карты data/map.json вместе с загруженными медиа и записанным голосом.

## Windows
Установите Python 3.10+ (для точного воспроизведения этой среды — Python 3.12), распакуйте архив и откройте PowerShell в папке InkMap:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-lock.txt
.\.venv\Scripts\python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

## macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Требуется интернет для установки Python-пакетов. requirements-lock.txt фиксирует версии текущей рабочей среды; requirements.txt содержит допустимые диапазоны.

Аудиозаписи находятся в document.nodes[].media[] внутри data/map.json (kind: audio, data: data:audio/...;base64,...). Отдельных аудиофайлов на диске нет. JSON-экспорт карты также включает записанное аудио.

Ссылки и указанные пути к внешним видео/файлам сохраняются как ссылки. Самих внешних файлов в архиве нет: скопируйте их отдельно и обновите пути при необходимости.

Архив содержит только уже сохранённую карту. Активная запись микрофона и несохранённая браузерная копия в него не входят. Настройка темы и разрешение микрофона привязаны к браузеру. История Undo/Redo хранится в памяти сессии и не переносится.

Окружение .venv, кэш, журналы сервера и временные снимки тестов исключены. Браузерные тесты необязательны для запуска и требуют отдельной установки Playwright и Edge. Приложение предназначено для локального использования; запускайте один процесс/worker.
